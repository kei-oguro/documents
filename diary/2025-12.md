12/19 金
--------

水やりは12:00にペットボトル1本。

__コーヒー__ をプレスで濃いめに淹れた。`珈琲や` の東京ブレンド。少し濃過ぎたかも知れない。

[Zwide SA11 に Bazzite を入れるとタッチ位置が反転する問題を gist に書いた](https://gist.github.com/kei-oguro/5bff14beebc73fb0c44045fd238044d6)。

長いこと日記を main ブランチに書き戻してないことを考えると、日記以外の文章は gist ないしは別のリポジトリにした方が良い。つまり、日記リポジトリを作って移行した方が良い。

`スターバックス` でクリスマスローストの豆と季節商品のホットアップルサイダーをテイクアウト。

__間食__ に知人に貰った `大心堂雷おこし` のおこしを食べた。

- スマホのプロバイダ選定。
  - POVO は通話可能なコースでも、基本料金無料らしい。トータル月額 2200円なら、文句ない値段かも知れない。さらに NMP 特典があったりしないかな？
    - au Pay 残高で 10000円くれるって。
    - あと、Amazon Prime の料金を1年間半分払ってくれるって。
  - POVO のサイトには AI チャットが無いようだ。すでにデータ専用アカウントがある状態で通話付きで MNP する方法が分からない。
    - データ専用を切り替えられないというのは書いてあるが、1アカウントで複数回線を契約できるようでもあるから追加したい。
      - 複数回線契約はできなかった。同一回線名義で年間5回、というのが事務手数料無料の条件で、それを見かけたのを混同していた。
    - 何も考えずに MNP したらいいのかな？
  - 解約が必要で、手続き中に何度も悲しい顔をされたり改善点を聞かれた。いや、2回線持てれば追加だけでいいんだけど。コッチも楽なんだけど。
- POVO への MNP の特典を受け取るために au ID に新規登録。
  - <img src='images/auID%E7%99%BB%E9%8C%B2%E3%81%A7%E3%83%91%E3%82%B9%E3%83%AF%E3%83%BC%E3%83%89%E3%81%8C%E5%A4%89%E6%9B%B4%E4%B8%8D%E8%83%BD%E3%81%AB%E8%A6%8B%E3%81%88%E3%82%8B.jpg' alt='auID登録 でパスワードが変更不能に見える.jpg' width='30%'> 記号込みの 20 文字でもパスワードの安全度が「中」だって。そして、「登録後は変更できません」という表記が生年月日ではなくパスワードを指しているように見える。
- OCN の契約期間はいつまでだっただろうか？ケチ臭く、ギリギリで乗り換えたいところだ。
  - 月末締めらしい。来週水曜辺りに手続きを始めようか。

__ランチ__ は袋キャベツと、ドンキで買ったガリバタ醤油味こんにゃく麺。味付けは粉末で、水切りしたこんにゃく麺にかけて、レンチンなり、フライパンで具材と炒めるなりして食べる。ちょっと高い気はするけど、3か月以上もつならストックしておいてもいいかも知れない。

- Bazzite に、Epic Games Store や GOG や Amazon Games で購入したアプリを起動する `Heroic Game Launcher` と、Microsoft Cloud Gaming にアクセスする `Greenlight` をインストール。
  - Epic Games Store にログインしようとしたら、サイト自体が落ちていた。が、10分後には復帰していた。
  - GOG にログインするために `Bitwarden` をインストール。
  - Epic, GOG, Amazon 全部あっさりログインできた。
  - `The Doors` をインストール。またセーブデータが無くなって最初から。
    - インストール直後には動かなくて、OS を再起動したら動いた。
    - 解像度を変更したら、タッチ位置がずれた。1920x1200 だと重くて不快だ。ゲーム性には関係ないんだけど。
      - どのレイヤーで変換にミスってるんだろうか？デバイスドライバが 1920x1200 のまま渡している可能性が高いか？タッチ位置反転の解消方法からすると。
  - `Loop Hero` は快適だった。Win11 の時に、一度タッチして選択してもう一度タッチして決定という操作方法だったが、一度で決定できる。Win の時は何かの設定の問題だったんだろうけど。
  - `Greenlight` はクラッシュした。残念。
    - そして、僕はこれでは遊ぶことが出来なかったことが判明した。
      - まず1つには、自宅の Xbox にアクセスするホームストリーミングで遊ぶことが出来る。
      - クラウド実行もできるけど Ultimate Game Pass が必要だそうだ。残念。
- クリップボード履歴ツールが、パスワードを表示しちゃうんだけど、どうしよう。他人が使うことが無ければ問題はないが。
- vscode をインストールした。
  - Flatpak 版は何か制限があるらしいが、今のところは日記を書くだけだろうから、問題になるか分からない。
    - deb や rpm でインストールするのは Silverblue 的な過ごし方の練習になるとも思うが、どんなものなのかな。
  - ログインの認証情報を記憶するのに kwallete を要求する。それが更に kgpg を要求するそうだ。やった方が良いし、経験して慣れておいた方が良いのは分かるんだけど、腰が重い。

アクセス確認のために Epic Games Launcher を起動して、無料の `Hordes of Hel` を貰った。ポリゴンのバンパイアサバイバーっぽいゲーム。

明日もシークレットゲームだそうだ。

__FX__ は利上げしたの円安が進んで利益が増えた。一旦利確しようかどうしようか。

- 鶏ムネ肉を煮る。半分は作り置きで、半分は稲庭うどんを食べるスープ。
  - 適当に切って、昆布と生姜と、余っていた料理酒で煮る。醤油が足りなかったので塩を適当に足した。分量は全く計ってない。
  - 鍋が小さ過ぎた。容量がギリギリだ。
  - アラーム付きの温度計で 80°C にセットして、何度か上下を返して、イイ感じの煮え具合にしようと思ったけど、鍋が小さいこともあるし、1度目のアラームで下の方の肉が生煮えで、このやり方はメリットよりも手間が多いと感じて、弱火で沸騰を待った。
  - 余熱で火を通す意味もあって、一度放置して温度が下がるのを待つ。肉の出汁が外に出るのと、塩分を吸うことも期待。
- 煮上がった時は柔らかくて美味しかったが、冷ましたら余熱で火が通り過ぎたらしく、硬くて美味しくなかった。
  - 下味を付けたら違うだろうか？それとも、もっと急速に冷ましたら違うだろうか？

- Win11 11インチタブレット `SA11` に `Bazzite` をインストールする話。
  - しばらく放置してたタッチ座標反転問題だけど、「それは違うだろう」と思ってた、min, max を反転して設定するやり方でちゃんと動いて驚いた。
    - etc/udev/hwdb.d/61-touchscreen-local.hwdb に以下を記述。デバイス名や解像度は Zwide SA11 の場合。
      ```ini
      evdev:name:NYM TCA9537-J12:*
       EVDEV_ABS_35=1200:0:1
       EVDEV_ABS_36=1920:0:1
      ```
  - デフォルト設定は、指で操作するには UI が小さい。
    - 200% にしたら、イイ感じになった。
  - 設定パネルの中で、ドラッグでのスクロールに対応しているところと、そうでないところがある。それぞれにコードを書いてるんだろうね。ゲーム内だったらこうはならないけど、色んな人が時間もプロジェクトも別々に実装してると、ある程度仕方がないかもね。

- SA11 いじり
  - 電池が切れるまで待って、朝になってようやく再起動できた。昨日は長押ししても、多分 Bazzite の、スリープモードに入るだけだった。
  - イミュータブル OS らしく、前回の画面回転の変更をキャンセルしようと、USB メモリから起動してトラブルシューティングモードに入ったんだけど、なんかエラーが出てて、調べるのが面倒だった。
  - 一回、再インストールしてみる。
    - ダメなら CachyOS かな？そっちでの設定も大変そうな気がするが。
  - 再インストール。
    - 前回はキーボードだけで済んだ気がするが、反応してるのかどうか、今どういう状態なのか、分かりにくいので Macbook から USB ハブを持ってきた。
  - 同じ現象になった。
    - 起動時に、画面は動かないのにそれらしい音が鳴っている。多分、外面が動いてないだけで、裏で Steam が動いている。
    - 音を頼りに再起動しようとしたが、メニューの位置を覚え違いしていて上手く行かなかった。
    - 同様に音を頼りにデスクトップモードに移行することには成功した。最後に確認ダイアログがあって、そこも音を頼りにデフォルトではない方を選択する必要がある。
  - **電源ボタン長押しの再起動をブロックするのは凄いな！**
  - 外部モニタを繋いだら表示された。ちゃんと横画面で。
  - [Gemini に聞きながら色々やって](https://gemini.google.com/share/aa934e801d5c) 、結局 Steam モードでの起動は諦めた。
    - KDE から Steam を実行したら Big Picture モードでも問題ない。
  - Desktop 向けの Bazzite をインストール。
    - Live ISO で、起動してからインストールを試してみた。あんまりメンテされてないかも知れない。パーティション分割画面でダークモード対応してなくてとても読みにくかった。また、言語選択がLive起動時に無い。
  - タッチ位置が180°回転してる問題は解決しない。
    - Gemini の言う通りにキャリブレーション行列を設定してみたが無視されている。udev ルールでの設定と、Hardware Database の設定の両方を試したが、両方ダメ。
    - 色々試してる間にタッチが全く反応しなくなったので再インストール。イミュータブルOSなんだからロールバックすべきだが、KDE の設定は対象会社じゃないかと思って、それを確かめもせずに再インストールした。
