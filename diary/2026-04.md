4/29 水 昭和の日
-------

水やりは15:00にペットボトル1本。

__ランチ__ は通販の乾麺のラーメンを、まいばすの冷凍チゲスープと袋野菜炒めを煮たものに入れて食べた。乾麺 180g を2回に分けて、熱いままと水道水で洗って食べ比べた。大抵の麺と同様に洗った方が美味しい。

収穫したニンニクを使った。薄皮が少しだけ生えていた。

結構前に、多分 `華僑服務社` で買ったハブ茶を金鍔と一緒に飲んだ。味は良く分からない。日本ではエビスグサと呼ぶという決明子の種を焙煎したものだそうだ。

__夜食__ にカップ飯パエリアにスライスチーズと卵。足りなかったのでシャウエッセン3本とスライスチーズ2枚をレンチン。

2018 年のツールのバージョンアップが svn にコミットしてなかったので追加した。NAS の移行を行うと、この設定をし直す必要がある。

長いことテキストエディタで Ctrl + Y をカーソル行削除に割り当ててきた。が、Windows の標準的な？キーボードショートカットで Redo が Ctrl + Y になっている。頭で理解していて、たまに使う。これが、たまに、vscode を使っていても Redo のために脳死で Ctrl + Y を使ってしまって Redo バッファが無くなってしまう。重い腰を上げて、vscode のキーボード設定の Ctrl + Y から1行削除を消した。Undo/Redo を Ctrl + Z/A に割り当てていてすぐに Undo 状態を行ったり来たりして目視確認できるようにしている。Ctrl + Y で慣れるようにして、 Ctrl + A も一般的な割り当てに変更しようか。どんな機能か知らないけど。1行消去自体はそれなりに良く使う。Ctrl + Shift + K だそうだ。覚えられるか。そして、職場と個人のアカウントの共有が許可されていないから、職場の割り当ても直さないと。

試してみたけど、いきなり不便だった。デバッグコードに仕込んだマークを検索して1行消去したんだけど、F3 -> Ctrl + Y は手を動かさずに繰り返すことが出来るけど、F3 -> Ctrl + Shift + K は右手をその度に移動する。Ctrl + Shift + K を3つとも右手で押せばいいのかな？

llama.cpp をアップデートして Qwen3.6-35B-A3B を試してみようと思ったら、以前に gpt-oss-20b を試した wsl 環境を消していたらしい。環境を切るのも面倒で、デフォルトの Ubuntu で llama.cpp をビルド。モデルをダウンロードしに行ったら4時間かかるって。35GBでそんなに遅いの？

RTX 5060 無印が 48000円でYahoo! フリマに出ていて、クーポンで3000円引き。迷う値段だ。欲しいけど、結局 vscode とソリティアくらいしか動かさないでしょ？オークションに 40000円で入札ゼロの出品があった。なんとなく札を入れたが、落札できて欲しいような、欲しくないような。50シリーズは MXFP4 が使えるから、ローカル LLM で有利。

WQHD 27インチ有機ELモニタの相場を見たら、セールなら6万円のがあった。そこそろ手を出しても良い頃かも知れない。

駄菓子屋の粉末ジュースが届いて、グレープとイチゴを飲んでみた。なかなか溶け切らないね。1袋9gで100mlの水。200mlの水でブレンドしてもいいかも知れない。

vscode で ctrl + P でのファイル検索で .claude 以下の git ワークツリーが引っ掛かって難儀した。vscode の設定を聞いて `"files.exclude": { "**/.claude" : true }` を追加。ついでに .git/config とかが見えないのが不便だったので .git は見えるが .git/objects は見えないようにした。

バグ調査で過去のログを見ていたら、".C" の拡張子が大文字だと C++ としてコンパイルされることに驚いているログがあった。[今回もこないだ驚いた](2026-01.md#0110-i-learned-the-upper-case-c-extension-is-cplusplus)。

7:00の目覚ましで8:00起床。

水やりは8:00にペットボトル1本。

20分早く家を出た。赤坂見附で思い出して、結局スルーしたけど、銀座線に乗り換えて日本橋で降りて `SRコーヒーロースター` もありだったかな。初挑戦ならもう少し時間の余裕が欲しいと思ったが、赤坂見附で1時間ならそんなものではないかという気がする。

vscode serveweb のクライアントからだとiOSでペーストできないが、トンネル接続からならできる。

こないだ、ソフトウェアキーボードにペーストボタンがあったけど、今日は見えない。いつ出るんだ？Safariでトンネルとかだったのかも。

最初から「iOSのソフトウェアキーボードにペーストボタンが」で書き始めてるのに、そっちじゃなくてという指摘に「ああ、それは長押しメニューじゃなくて」と言ってくるChatGPT。この態度はなんとかならないのか。無料ユーザーをイラつかせて有料プランを契約させたいの？

八丁堀で降りて `タニタカフェ` でホットコーヒーをテイクアウト。クロロゲン酸が豊富だという。悪くないが美味しいという範囲にはないと感じる。

html に、説明と本体、という構造になっている要素が少ない。欧米の文書の構造にかんする哲学なのだろう。この日記もそうだし、開発の文書もそうだが、この箇条書きはなんなのかという注釈を付けたいが、丁度良いものがない。`<div>` にまとめる？表示はともかく意味的にはそういうのもじゃないよね。図表の類だと思えば`<div>` でもいいのか？そんなことないよね。なんなら `p` にキャプション属性が欲しい。`<img>` タグの `alt` みたいな `title` ってグローバル属性があるのか。そういう話じゃないんだけど。

昨日、画像ファイルの名前に「にもかかわらず」の意味で辞書を引いて though を使ったが、普段はもっと簡単な表現を使っていたよなと思っていた。今日思い出したが even if だ。仮定の表現の中でも、昨日のは「これが事実にもかかわらず」という意味だったので、たまたま適切だった。even if, though, although, even though とあって覚えられない。

`江戸深川珈琲本舗` のスペシャルブレンドを、熱湯で速めに淹れた。前回からは豆の量が減っている。面白みが減った。次回はミルの目盛りを 6 → 8 にして、粗めの多めで淹れてみたい。前回目盛りを 8 → 6 にした時は勘違いで粗くするつもりだった。まあ、10 は多分粗過ぎるから、それで良かった。細かくして美味しくなったし。

最近ピノキオが開いてるのを見ないが、営業曜日告知の紙も無くなってる。他の2枚の貼り紙が残っているのは、再会するつもりがゼロではないということだろうか。

Qi の充電がやたら遅いことがある。iPhone SE3 で MagSafe 非対応で、ケースに磁石リングを貼ってあるが、多分中心がズレてると遅いのではないか。充電スピードをリアルタイム表示してくれて調節できるといいんだけど、そんな値は取れないよね、きっと。

南砂町って何だろうと思っていたが、砂町ってのがあって、砂町銀座商店街ってのもあるんだそうだ。江戸時代は農園地帯だったとか。
