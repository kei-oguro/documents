そろそろ Wi-Fi ルータを買い替えても良さそうだと思うが、6, 6e, 7 と、値段と性能と必要性からどれを選ぶべきか、自分の中で方針が固まらない。

- VPN 経由で lfs を含む git リポジトリのアクセスに苦闘。
  - Caddy は winget に GitHub の Release の最新と同じバージョンがあった。Gitea は 数字がまあまあ小さく、名前も公式か分からない。Chocolatey にあった。`choco install gitea`
  - Gitea の セットアップでユーザ名とパスワードを入れろと。データベースのにも見えるけど、gitea gitea で構わないかな？
  - Gitea 経由でアクセスする全ての lfs ストレージが一緒くたにされてしまう。意味は理解できるが、lfs に格納されたブロブも含めてリポジトリ毎に扱いたい。リポジトリの数だけ Gitea を動かす？リポジトリを増やしたりアーカイブして削除するのが面倒だ。
  - Gemini によると、lfs サーバを書くのは簡単だってさ。
    - git-http-backend と自前スクリプトの2本立てを進められたが、lfs 対応の git-http-backend をgit lfs install でいれてくれればいいのに。

Android cli だって。事前学習？追加学習？したものっぽい。半年前にあると良かったけど。

`東亜サプライ` というカフェで、派遣元？のクリーク&リバーの方と面談。お叱りかと思っていたが、前向きな話でホッとした。アイスコーヒーがおいしかった。

電車の中から Parsec で MacBook から 自宅の Windows デスクトップに接続する。IME の切り替えがキーボードからできない。Gemini の提案に従って Power Toys を導入する。`winget powertoys`。が、都庁前から繋がらなくなって諦めた。

- 自宅に戻って、Mac から Parsec で繋いだ時の IME 設定について色々試す。
  - Gemini の提案は全部ダメだった。が、Gemini が Parsec の Hoykeys 設定画面を教えてくれて、そこから Parsec 公式ページの説明にたどり着いた。 Cmd+Space が macos の Spotlight になっていたが、それをカットするのに、System Settings の Accessibility で Parsec を許可し、Parsec では Immersive Mode にすることで、無事に Cmd+Space で IME 切り替えができるようになった。
  - Gemini の提案で PowerToys のキー入れ替えで mac の「かな」「英数」キーを入れ替えようとしたが、Parsec 経由で送信しても反応しない。送信してるのかな？
  - Mac の Caps Lock を変更するのが一番の気はするけど。
    - Caps Lock は全く必要ないんだけど、たまに誤爆するので、間違って押しても害のない機能である現在は、そう悪くもない。

本人の手紙があるからといって、その内容が事実かどうかは分からない。書かされたかも知れないし、代筆かも知れない。なんなら、「ChatGPT のせいにしたら娘が悪くないように見える」ということで生成してくれたかも知れない。
