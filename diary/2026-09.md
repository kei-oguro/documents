戻りに `zentaコーヒー` でプエルトリコだったかな？

`git reset –hard && git switch <target-branch>` は `git switch -f`

- GitLab がフォーマッタでの1行文字数を変更したのを無視したいので WinMerge で diff を見たい。
  - ~/.gitconfig に WinMerge を登録したうえで `git difftool --dir-diff origin/HEAD...origin/target-branch` とすると、コミット同士のフォルダ比較ができる。素晴らしい。fetch してあれば switch する必要がない。
    - WinMerge で差分のあるすべてのフォルダを展開するキーボードショートカットは Alt + V -> X -> D
  - ブランチ元との比較は `HEAD...target-branch` だが、直接の親と比較したい場合は `target-branch~ target-branch`
