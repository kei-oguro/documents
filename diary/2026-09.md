9/7 月
------

水やりは9:00にペットボトル1本。あげなくても良さそうだったが、様子を見る前に水を汲んでいたので。


9/6 日
------

水やりは12:00にペットボトル1本。雨降りだけど、手前のライムの鉢には雨が届かない。

目方が2kg増えてほぼ80kg。長いこと安定していたけど。

__ランチ__ は甘いもの。

東中野と代々木の飲み屋を4軒回る。途中東中野の家系ラーメンの `ばく` で冷やし豆乳ラーメンを __晩飯__ に頂く。

9/5 土
------

水やりは16:00にペットボトル2本。

__ランチ__ は通販の麺だけ喜多方ラーメンをスーパーの個別包装の鶏ガラ醤油味のスープにラードと魚粉を入れたもので。追加で素麺。

__晩飯__ はランチのスープで素麺。直接茹でて、お湯が足りなくて面倒なことになったし微妙な仕上がり。

知り合いのお祝いで歌舞伎町のスナックへ。そして歌舞伎町の `どないや` でたこ焼きを買って東中野のバーにお祝いに。帰りに近所の飲み屋に寄って帰宅。

エアコンを消して寝た。もう何日も必要なかったんだけど、何故か設定を28°Cにして寝てた。

昼に起きて、風邪の症状があるのでそのままお休みさせて貰った。

__ランチ__ はカップ麺と素麺2束とポテトチップス。


9/3 木

早く起きたのに10分早く出ただけで、道中でモンハンナウをしていて3分早い電車に乗っただけ。

昼休みに、今の職場を紹介してくれてるクリークアンドリバーの担当者と電話。家賃の引き落としに失敗していたの振り込み。スカウトメールへの返信。

`オフコーヒー` でたまごサンドとカフェオレをテイクアウト、まいばすでサラダを購入。昼休みにやることがあったので __ランチ__ は買ってきたもの。



9/2 水
------

8:00の目覚ましで8:50起床。

水やりは9:00にペットボトル2本。昨日雨だっけ？

git の sparse-checkout 設定にワイルドカードを許さない代わりに検索が速い cone モードというのがあるそうで、 code-review の worktree を作った時に何も考えずに AI の言うままに --cone を付けたら、sparse-checkout のリストにワイルドカードが入っていると警告が出てうるさい。使うリストは CI でのユニットテストのために元々存在するもので、すでにワイルドカードが使われていた。それで --cone モードを解除したいんだけど、と Gemini に相談したら git sparse-checkout disable してまたやれという。config ファイルを編集したらできるだろう、と見てみると実際に `[core] sparseCheckoutCone = false` がある。僕の欲しかった回答は `get config core.sparseCheckoutCone false` だよ。デフォルトの品質がいまいちだ。

__ランチ__ は `ビストロアポロン` でバラ焼きカレー。目黒でランチにリピートするのは2軒目。1軒目はお盆期間の `巧匠` 。

戻りに `イトーヤ` でアイスコーヒーをテイクアウト。アイスは汲み置きだった。

vscode.dev でアクセスする時には専用のプロファイルで markdown 拡張を切ったハズなのに有効になってる。再認証がきっかけだと思えるタイミング。

vscode.dev でアクセスしたときのプロファイルは、設定がブラウザに紐づいている。

__晩飯__ は `麺屋周郷別雅` で辛つけ麺。

駅の近くの立ち飲み屋 `ビストロShin` で一杯。いつも満席の札が出ているが、今日は入れてラッキー。軽く飲みたいと思って「立ち飲み」の店を試したが、ビストロの名前らしい料理だった。食べ過ぎた。


9/1 火
------

8:00の目覚ましで8:40起床。

水やりは13:00にペットボトル3本。

お腹を冷やしたようで腹痛で遅刻させて貰った。

__ランチ__ は新宿駅の `信州そば本陣` で冷やし鶏そばとかき揚げ。かき揚げは深皿に入れて温かいそばつゆを掛けて提供してくれた。素晴らしい。同じ新宿駅の `箱根そば本陣` も名前に本陣とつく。検索しにくい。

- Unity Accelerator というアセットインポートのキャッシュシステムがある。
  - サーバを立ててチームで共有するような用途が想定されているが、ローカルで有効にしてもブランチや worktree を行ったり来たりしたら、さっきインポートしたものはコピーで済むようになる。実際のところどのくらい変わるのだろうか。コピーと大差ない可能性もある。
  - これが有効だとすると、帰宅時にどこかの worktree で pull origin/main して Unity をバッチモードで起動したら夜の間に更新分のアセットインポートが走るんじゃないかと期待する。
    - コンソールからバッチモードで立ち上げるとすぐに制御を戻してしまう。`start /wait "Window Title" exec params...` で終了待ちできるそうだ。 `C:\Program Files\Unity\Hub\Editor\edirot-version\Editor\Unity.exe -quit -batchmode -projectPath . -logFile unity.log` のようにして、`shutdown /h` で休止状態にできる。`git fetch` 、 `git reset --h origin/main` のコンボで運用できるといい感じかも知れない。

`-logFile` は Unity Hub に登録しているプロジェクトごとに設定した方が便利。なんでログをデフォルトでプロジェクトフォルダ内に出力しないんだろう。

餃子が有名で予約が取りにくいらしい目黒の百名店の `鎮海楼` で __晩酌__ 。ニラ水餃子、揚げ餃子、麻婆豆腐ハーフ、もやしの冷菜。

寝ようとしたら照明のリモコンが見つからない。今朝起きた時に点けて、どこに置いたか分からない。外出帰宅時は入り口のスイッチで切り替える。
