9/4 木
------

8:30の目覚ましで9:30起床。

- __園芸__
  - 水やりは10:00にペットボトル5本。
  - __オクラ__ を1本収穫。
  - __タマリンド__ の発芽ポットから小さな芽が2つ出てるけど、サイズ的にこれは土に種が混ざっていた雑草では？

- 朝起きて、[昨日の朝やった AOSP のクローン](#0903-cloning-AOSP)の結果を見たらネットワークエラーで？失敗してた。
  -  いつ頃からだろうか、以前はそうではなかったと思うんだけど、ガッツリとダウンロードしてると他の端末のパケットがほとんど通らない。ネットワークの調子か、ルータの調子か、git の実装がウチの環境で賄えないほど貪欲か。
  - もう一度実行してみると、失敗した場所は昨日のとは違っていた。いくらかは進んだのではないか。
    ```
    Try re-running with "-j1 --fail-fast" to exit at the first error.
    ```
    というメッセージを含んでいる。失敗したのは`-j8`で、`j`はジョブの数だって。貪欲に試すのを自分で指定してたワケだ。AOSP のサイトからクリップボードにコピーしたコマンドだけど。
  - `-j1`にしたら完了した。
  - ブランチが設定されておらず、ワーキングコピーに何もない。いや、.repo にも何もなかった！
  - ああ、
  - ```
    sudo mount -t drvfs "C:\\Users\\masuo\\Documents" Documents
    repo init --partial-clone -b main -u https://android.googlesource.com/platform/manifest
    ```
    パーミッションエラー。検索したら AI が WSL を再起動してみろというので`exit`して`wsl --shutdown`してもう一度入ったら動いた。


9/3 水
------

8:00の目覚ましで8:50起床。

水やりは9:00にペットボトル6本。

DeepWiki に termux-x11 のリポジトリを掛けてみた。   
https://deepwiki.com/termux/termux-x11  
パッと見、OpenGL を termux から使えそう。こないだターミナルエミュレータを検索した時に、ネイティブグラフィックスがどうこうを売りにしてるのがいくつかあって、それらが本領を発揮できるのかも知れない。

Samsung の端末も Android16 のターミナルアプリを Kingrid と同じ理由で起動できないそうだ。  
https://x.com/DevOfIpos/status/1920501982227300785 

<a id="0903-cloning-AOSP"></a>エラーが出ている部分のソースを見たくて、 [Android Open Source Project](https://source.android.com/) のリポジトリをクローン。
