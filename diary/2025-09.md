  - WPC04 で 2D ゲームに十分だったら良かったんだけど、Loop Hero でさえ重過ぎる。
    - N150 は N4020 の4倍の速さだそうだがどうだろうか？

  - SA11 が7千円で手に入らないかな？WPC04 も相場よりずっと安くフリマに出ていて、少し期待したい。
    - 今のところ、メルカリでキーボード付き29800円、ヤフオクでキーボード無し24000円。安いとは思うが、衝動買いする値段ではない。

Windows とか Program Files の削除が終わらない。後何をしろというのか。

https://store.steampowered.com/app/2949320/Ratatan/

Android16の端末と Kindle fire の性能差を見たくて Geek Benchmark6 をダウンロードしたが、Android16 の端末では動かなかった。エラー通知っぽいダイアログが空っぽで、何の情報もない。が、再起動したら動いた。Kindle の方が速い。なんかそんな気がしてた。Kindle:Kingrid は CPU が 2236:1379 で GPU が 1161:699。倍近い。公式の Terminal が動かないなら僕には価値が無い。ああ、メモリは多いのか。調べ物でアチコチのサイトを開いた後に vscode が生き残っている可能性が上がる。8GB 物理メモリに 16GB スワップメモリ。

金ザルをAmazonで注文。麺類を洗って冷やすのに丁度良いサイズが無かった。こないだダイソーやスーパーに見に行ったら、ダイソーには良いサイズが無く、近所のスーパーは1000円以上のしかなかった。

DistroWatch を見てたら Linux ではない OS が乗っているのを知った。ReactOS とか。

  - 他のも5万円は超える価格で落札されそうだ。

- <details><summary>__Fedora__ について興味が出て調べものをしている。</summary>

  - 元々のきっかけは Snap が Termux on Kindle で動かなかったから、別のパッケージマネージャを使ってるシステムに乗り換えようか、というもの。
  - Red hat ベースのOSはサーバサイドではまだ人気が高いらしいので、何が違うのか少しは知れたらいいな、ということもあって、Debian 系の何かで人気があるもの、という選択。Termux の proot-distro にイメージがあるのも良い。CentOS は無かった。
  - __Silverblue__ とか __Kinoite__ というディストロがあってイミュータブルなOSというのが売りだそうで、**/etc と /var 以外は書き込み禁止** なのだそうだ。ユーザーからの見た目は chroot 的な環境で /etc/home/username 以下にストレージのイメージがあって、インストールするものはそこに配置することで、破壊的変更をキャンセルできるようにするということらしい。
    - proot-distro ももう少し徹底してくれると、Snap も含めて色んなものが動くようになるのではないか。
    - chroot 的と言ったが、Docker や Podman を使用するそうだ。
    - Toolbox というのでコンテナを管理するそうで、何か試したいときはコピーを作ってそこで作業して、上手く行ったらそちらを普段使いにしたらいい。
      - Docker でそういう風にやってる人もいるらしいけど、Dockfile を書く必要が無い。
      - proot-distro でも似たようなことはできるはずだ。termux レベルにインストールするものを絞れば、気軽に色々試せそう。
      - Toolbox と別に __Distrobox__ というのもあるそうで、そちらは Ubuntu や Arch や Alpine なんかを入れられるらしい。そうやって入れ子にしたら Snap も動くかも？
      - toolbox はただの padman のラッパースクリプトだと言ってる人が Reddit にいた。
  - 調べ物をしていて、ディストロという単語に慣れて普通に出てくるようになった。
  - Fedora に sudo グループが無い。 /etc/sudoers を見ると wheel グループに権限がありそうで、グループは追加したのに動かない。結局 /etc/sudoers でフルアクセルの行をコピーしてユーザー名を指定した。
  - `dnf install distrobox`したが、`cpio: open failed - No such file or directory`とか`cpio: symlink failed`で、1つも依存パッケージをインストールできない。
    - `sudo`忘れてた。たった今まで何をやっていたのか、俺は。
    - Toolbox のパッケージ名は`fedora-release-toolbx`。
      - 使い方が分からない。
      - `man`コマンドが無い。
    - `distrobox ls`を実行したら面倒そうな podman の警告と、`runc`が無いというエラーが出た。今日はここまで。
  </summary>
