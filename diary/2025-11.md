__夜食__ にセブンのおにぎり「えびめし」。

- `Code Spell Checker`(`cSpell`) vscode プラグインの設定
  - まとまった辞書 [`CSpell Bundled Dictionaries`](https://marketplace.visualstudio.com/items?itemName=streetsidesoftware.code-spell-checker-cspell-bundled-dictionaries) があって、これをインストールして settings.json や cspell.json で `"languageId": "c,cpp"` と設定することで、`NDEBUG` が単語として扱われるようになった。多分 python とかもあるので設定が楽になると思う。
  - 作業日誌に設定したかった。"docs/daily-report" というフォルダにプロジェクト毎に .md を置くようにした。そのフォルダに "cspell.json" を作成して、その中で以下のようにすることで、プロジェクト毎に扱う言語を手軽に設定できるようになった。
    ```json
    {
      "overrides": [
        {
          "filename": "some-project.md",
          "languageId": "c,cpp"
        }
      ]
    }
    ```
  - [CDN からの辞書インストール](https://www.npmjs.com/package/@cspell/dict-win32#local-installation-using-cdn) なんてのもあるんだね。

Crossover は年額のサブスクリプションだけど、サポートが無いだけでそのまま使えるというライセンスだそうだ。延長だと半額だって。

- mac での gpt-oss-20b のパフォーマンスを見てみたい。
  - 僕の mac のメインメモリは 16GB なんだけど、その量では、一説には、他に何もアプリを動かせなくなると。

  - `brew install llama.cpp` して `llama-cli -hf unsloth/gpt-oss-20b-GGUF` した。放置して2時間後に見たら、あと2時間かかるって。そこで中断して、こないだダウンロードしたのを使うことにした。
